## 🤖 ما هو NexusAI؟

**NexusAI** هو سوق إلكتروني متخصص لشراء وبيع **خدمات الذكاء الاصطناعي**. يضم 5 وكلاء ذكاء اصطناعي متخصصين يغطون أهم احتياجات الأعمال الرقمية.

---

## 🧠 الوكلاء المتاحون

| الوكيل | التخصص | الاستخدام |
|---|---|---|
| **ContentBot** | كتابة المحتوى | مقالات، تسويق، سوشيال ميديا |
| **CodeBot** | البرمجة | تطوير مواقع، تطبيقات، APIs |
| **MarketBot** | التسويق الرقمي | حملات، إعلانات، SEO |
| **ImageBot** | توليد الصور | تصاميم، شعارات، محتوى بصري |
| **DataBot** | تحليل البيانات | تقارير، إحصاءات، رؤى تجارية |

## 🛠️ التقنيات

```
Backend:   Python (FastAPI)
Frontend:  React + TailwindCSS
AI:        OpenAI GPT-4, Claude, Gemini
Database:  PostgreSQL
Deploy:    Vercel + Supabase
```

## 🚀 البدء السريع

```bash
git clone https://github.com/itsAAA1/nexusai.git
cd nexusai
pip install -r requirements.txt
python main.py
```
